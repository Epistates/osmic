# Test fonts

`Cantarell-Regular.ttf` is bundled so text shaping, placement and golden-image
tests are deterministic and do not depend on system fonts.

Jakub Steiner, and is licensed under the SIL Open Font License, Version 1.1
(<https://openfontlicense.org>; the license text is embedded in the font file's
name table and reproduced in `OFL.txt`). The font is used here unmodified and
only by tests; it is not part of the published crate API.
